# MediConnect
Hospital Management System — ADSE 2509 (Group 3)

## How to Run
1. Install **JDK 25** and **Apache NetBeans**
2. Clone this repo
3. Open NetBeans → **File → Open Project** → select this folder
4. Press **F6** to run

## Login

- Password: `admin123`

## Database
Run `sql/schema.sql` in SQL Server Management Studio to set up the database. If SQL Server is not available, the app runs with in-memory data automatically.
